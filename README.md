with the use of basic HTML and basic CSS programming languages

first of all create the (index.html) file in a folder
then similarly create the (styles.css) file in the same folder
link the css file with the html file using the [  <link rel="stylesheet" href="styles.css">   ]

add the hotel images required to the project 
place the images in the same project folder 

then copy the index.html source code  file 
paste the code in their respected file { index.html }

then copy the styles.css source code  file 
paste the code in their respected file { styles.css }
